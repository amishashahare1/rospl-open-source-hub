
## Contribution Workflow

This project demonstrates open-source contribution practices using Git and GitHub.

### Technologies Used
- HTML5
- Bootstrap CSS
- Java
- TypeScript
- Git and GitHub

### How to Contribute
1. Fork the repository.
2. Clone your fork to your computer.
3. Create a new feature branch.
4. Make your changes.
5. Commit your changes.
6. Push the branch to GitHub.
7. Open a Pull Request.
8. Review and merge the changes.

### Project Features
- Add contributions
- View recorded contributions
- Delete contributions
- Save contributions in browser local storage
